# Mutual Fund Analytics — Capstone Project I

## 📌 Project Overview
This project analyzes mutual fund NAV data using Python.  
It covers data ingestion, cleaning, analysis, visualization, and reporting.

## 📂 Folder Structure
- `data/raw/` → raw NAV datasets (CSV + API fetches)
- `data/processed/` → cleaned datasets (`cleaned_nav.csv`, `nav_with_returns.csv`)
- `reports/` → charts (`nav_trends.png`) and final report (`report.md`)
- `scripts/` → Python scripts (`data_ingestion.py`, `data_cleaning.py`, `analysis.py`)
